# Contributing

Macatia is a tool I use every day for my own work, shared as is. It is open
source but not open to contributions: I don't review or merge pull requests, and
I don't take feature requests.

You are free to fork it and make it your own under the [MIT license](LICENSE).
[DEVELOPMENT.md](DEVELOPMENT.md) explains how to install a checkout and run the
test suites.
